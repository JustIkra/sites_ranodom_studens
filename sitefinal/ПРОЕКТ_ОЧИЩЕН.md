## 🚀 Как запустить проект:

### **Команды для запуска:**
```bash
# 1. Активировать виртуальное окружение
.\venv\Scripts\Activate.ps1

# 2. Установить переменные окружения
$env:DJANGO_ENV = "local"
$env:DJANGO_DEBUG = "1"

# 3. Запустить сервер
.\venv\Scripts\python.exe manage.py runserver
```

### **Или одной командой:**
```bash
.\venv\Scripts\Activate.ps1; $env:DJANGO_ENV = "local"; $env:DJANGO_DEBUG = "1"; .\venv\Scripts\python.exe manage.py runserver
```

## 📝 Примечание:

Если нужно изменить фронтенд:
1. Редактируйте файлы в папке `new-zakaz/src/`
2. Выполните `cd new-zakaz && npm run build`
3. Скопируйте `new-zakaz/dist/index.html` в `templates/index.html`
4. Перезапустите Django сервер
