# Инструкция по добавлению изображения Александра Почикаева

## Что нужно сделать

1. **Замените файл изображения:**
   - Найдите файл `new-zakaz/public/images/alexander-pochikaev.jpg`
   - Замените его на реальное фото Александра Почикаева
   - Рекомендуемый размер: 400x400 пикселей (квадратный формат)
   - Формат: JPG или PNG

## Где используется изображение

Изображение Александра Почикаева отображается в двух местах:

1. **Компонент About.tsx** - большое изображение слева от текста "О себе"
2. **Компонент OurMission.tsx** - маленькое круглое изображение в карточке с цитатой

## Технические детали

- Изображение загружается из папки `public/images/`
- Путь к файлу: `/images/alexander-pochikaev.jpg`
- Круглое изображение автоматически обрезается с помощью CSS `object-cover`
- Большое изображение имеет скругленные углы и тень

## Проверка

После замены файла:
1. Запустите проект: `npm run dev`
2. Откройте главную страницу
3. Проверьте, что изображение отображается корректно в обоих местах
