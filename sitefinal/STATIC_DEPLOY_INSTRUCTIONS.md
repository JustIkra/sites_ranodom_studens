# Инструкция по загрузке React приложения на статический хостинг

## Проблема
Картинки не отображаются на статическом хостинге, потому что пути указывали на `/static/images/`, а должны быть `/images/`.

## Решение
Исправлены пути к изображениям в React компонентах.

- `index.html` - главная страница
- `vite.svg` - иконка Vite
- Папка `assets/` - JavaScript файлы

## Пошаговая инструкция

### 1. Загрузите файлы
Загрузите все файлы из папки `new-zakaz/dist/` на ваш хостинг в корневую папку.

### 2. Проверьте структуру
Убедитесь, что:
- `index.html` находится в корне
- Папка `images/` содержит все изображения
- Папка `assets/` содержит JavaScript файл

### 3. Проверьте сайт
Откройте ваш сайт и проверьте:
- Загружается ли главная страница
- Отображаются ли картинки
- Работают ли все функции

## Что было исправлено

В следующих файлах изменены пути к изображениям:
- `src/components/About.tsx`: `/static/images/` → `/images/`
- `src/components/OurMission.tsx`: `/static/images/` → `/images/`
- `src/pages/ProjectPage.tsx`: `/static/images/` → `/images/`
- `src/components/QRCode.tsx`: `/static/images/` → `/images/`
- `src/components/icons/Logo.tsx`: `/static/images/` → `/images/`

## Если картинки все еще не работают

1. Откройте консоль браузера (F12)
2. Посмотрите на ошибки 404 для изображений
3. Проверьте, что файлы действительно загружены в папку `images/`
4. Убедитесь, что пути в консоли соответствуют структуре на хостинге
